# Dingel Hafizia App — Clean Restart

Firebase is intentionally excluded from this restart. The application is structured so authentication/cloud services can be added later without replacing the current core.

## Current stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MongoDB
- Authentication: not connected yet

## Project direction
Admin and Teacher roles only. Build the professional Madrasa ERP modules incrementally while keeping Firebase excluded for now.
